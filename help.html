내 목록과 게시물을
한눈에 비교하세요.

소장한 도서를 등록하면 게시물 제목과 비교해 제외·미완·완결을 표시합니다. 새 권수, 더 높은 해상도, 빠진 권수를 확인하는 흐름을 예시로 익혀보세요.

예시로 체험하기 →옵션 설명 보기
  1. 1

    사이트 등록

    ‘사이트 및 설정’에 사용할 사이트의 도메인을 추가합니다.

  2. 2

    소장 목록 입력

    제목·권수·해상도를 입력하고 제외 / 미완 / 완결을 선택해 저장합니다.

  3. 3

    게시물과 비교

    사이트를 새로고침하고 제목 옆 배지와 UP 표시를 확인합니다.

EXAMPLE 01

게시판 목록에서 먼저 확인하기

아래는 가상의 도서 게시판입니다. 제목을 클릭하면 상세 예시가 열립니다. 적용 전후를 비교하고, 우측 하단의 ‘게시물 숨김’ 스위치로 분류별 숨김을 체험해 보세요.

실제 확장 프로그램과 같은 배지·숨김 규칙·디자인을 사용하는 체험용 예시입니다. 조작은 실제 소장 목록이나 설정에 저장되지 않습니다. 실제 배치와 제공 기능은 사이트에 따라 다를 수 있습니다.

분류게시물 제목 / 내 목록 배지확인할 내용

제외

제목에 취소선을 표시합니다. 관심 없는 작품을 구분할 때 사용합니다.

미완

모으는 중인 작품입니다. 소장 권수와 해상도를 비교합니다.

완결

수집을 마친 작품입니다. 더 높은 사양의 게시물도 확인할 수 있습니다.

UP / 누락

UP은 등록값보다 높은 권수·해상도, 누락은 직접 지정한 빠진 권수입니다.

배지의 권수·해상도는 내가 등록한 값입니다. 게시물의 값이 더 높으면 해당 값 옆에 UP이 표시됩니다. 신작은 내 목록에 매칭되지 않은 게시물을 뜻하며 실제 출간 시점을 의미하지 않습니다.

EXAMPLE 02

상세페이지에서 등록·갱신하기

목록에서 선택한 게시물의 제목과 소장 정보를 비교합니다. 실제 화면과 같은 배지와 퀵 버튼으로 분류 변경, 삭제, 누락관리를 체험하세요. 검색 버튼은 체험 화면에 검색어를 표시합니다.

게시물 본문 예시

이번에 정리한 도서의 권수와 이미지 해상도를 제목에 기재했습니다. 제목에서 읽은 정보와 내 소장 목록을 비교한 뒤 필요한 항목을 갱신하세요.

예시에는 실제 파일이나 다운로드 링크가 없습니다.

처음 사용하는 사이트라면

  1. 실제 사이트의 도서 상세페이지를 엽니다.
  2. 책 제목 위에서 마우스 오른쪽 버튼을 누릅니다.
  3. ‘이 요소를 상세페이지 제목으로 등록 (버튼 표시)’를 선택합니다.
  4. 필요하면 새로고침 후 제목 주변의 등록 버튼을 확인합니다.

DOM은 페이지의 요소 구조입니다. 제목 요소를 지정하면 확장 프로그램이 상세 제목을 찾는 기준으로 사용합니다.

빠르게 등록하는 다른 방법

  • 게시물 제목 링크를 우클릭해 ‘제외 추가’, ‘미완 추가’, ‘완결 추가’를 선택합니다.
  • 링크가 없는 제목은 텍스트를 드래그한 뒤 우클릭 메뉴를 사용합니다.
  • 등록된 항목은 배지와 퀵 액션으로 관리할 수 있습니다.
  • 잘못 읽힌 제목·권수·해상도는 옵션의 도서 목록에서 수정합니다.

OPTION TAB 01

도서 목록 관리

소장 정보의 기준이 되는 탭입니다. 상단 통계에서 전체·완결·미완결·제외 항목 수를 확인할 수 있습니다.

여러 도서를 한 번에 등록하기

  1. ‘새로운 도서 일괄 등록’에서 저장할 타입을 선택합니다. 기본값은 제외이므로 모으는 중인 도서는 미완으로 바꿉니다.
  2. 한 줄에 한 작품씩 제목, 권수, 해상도를 입력합니다.
  3. 추출 미리보기를 확인하고 ‘목록에 일괄 추가하기’를 누릅니다.
별빛 도서관 3권 1500px
구름 우체국 8권 2000px
바람의 기록 5권 1500px

같은 제목으로 인식되는 기존 항목은 입력 정보로 갱신될 수 있습니다. 대량 등록 전에는 데이터 백업을 권장합니다.

제목 검색 / 정렬
저장된 제목을 검색하고 최신·오래된 등록순 또는 제목 가나다·역순으로 정렬합니다. 목록은 페이지 단위로 표시됩니다.
목록 찾기
‘중복 찾기’는 제목이 겹치는 항목, ‘누락 찾기’는 빠진 권수가 등록된 항목을 찾습니다. ‘폴더 규칙 찾기’를 선택한 뒤 규칙명을 입력할 수도 있습니다. 검색어 예: #중복, #누락, #폴더규칙:만화.
검색된 결과 타입 일괄 변경
현재 검색 조건에 해당하는 결과 전체를 선택한 타입으로 변경합니다. 검색을 비우면 전체 목록이 대상이므로 적용 범위를 먼저 확인합니다.
행별 수정 / 삭제
타입, 제목, 해상도, 권수, 상위 폴더 규칙을 고친 뒤 해당 행의 ‘수정’을 누릅니다. ‘삭제’는 소장 목록에서 항목을 제거합니다. 지원되는 작업은 화면 우측 하단 ‘실행 취소’로 되돌릴 수 있습니다.
제목정정
제목 입력칸에 올바른 이름을 적은 뒤 옆의 ‘제목정정’을 누르면 기존 제목이 동일한 항목을 함께 고칩니다. 이후 제목 인식에 사용할 보정 규칙도 저장합니다. 확인창에 표시되는 대상 수와 변경할 제목을 확인하세요.
상위 폴더 규칙
자동 폴더 다운로드 시 책 폴더 위에 둘 분류 경로입니다. 예: 만화/연재. 입력칸의 경로 미리보기로 결과를 확인하고 저장합니다. 규칙 옆 일괄 변경 버튼으로 같은 규칙을 사용하는 항목을 함께 수정할 수 있습니다.
+누락 / 누락 배지
먼저 숫자로 된 권수를 입력하고 ‘수정’으로 저장합니다. 권수 옆 배지를 누른 뒤 빠진 번호를 클릭하면 자동 저장됩니다. 다시 누르면 누락이 해제됩니다. 예: 5권까지 소장했지만 2권이 없으면 2를 선택합니다.

OPTION TAB 02

사이트 및 설정

어디에서 작동할지, 제목을 어떻게 읽을지, 어떤 보조 기능을 사용할지 설정합니다. 체크박스 변경은 바로 저장됩니다.

사이트와 제목 인식

작동 허용 사이트 / 상세 DOM
실제 사용할 도메인을 입력하고 ‘수동 추가’를 누릅니다. 입력 형식 예시는 books.example.com입니다. 상세 제목은 실제 페이지에서 우클릭으로 지정합니다. 등록 항목의 ×는 해당 사이트 등록을 삭제합니다.
제목 파싱 금지어
작가명이나 반복되는 홍보 문구처럼 제목 비교 전에 제거할 문자열을 등록합니다. 예: ‘샘플편집팀’을 등록하면 ‘별빛 도서관 샘플편집팀’에서 해당 문구를 제거합니다. 실제 작품명에 들어가는 일반 단어는 신중하게 추가하세요.
판본 식별 괄호 키워드
‘신장판’처럼 판본을 구분하는 단어를 보존합니다. ‘별빛 도서관(신장판)’과 ‘별빛 도서관 신장판’은 같은 판본으로, 일반판과는 별도 작품으로 매칭합니다.

다운로드와 브라우저 동작

자동 폴더 생성 다운로드
지원되는 바로다운로드 기능을 사용할 때 책 제목으로 폴더를 만듭니다. 도서에 상위 폴더 규칙이 있으면 함께 반영합니다. 일반적인 모든 웹 다운로드에 적용되는 설정은 아닙니다.
다운로드 현황판 표시
지원되는 다운로드의 진행 상황을 화면 좌측 하단 현황판에 표시합니다.
확인창(Confirm) 자동 스킵
지원되는 페이지의 반복 확인창을 자동으로 넘깁니다. 포인트 차감 같은 확인도 포함될 수 있으므로 내용을 직접 확인하려면 꺼두세요.
활성 탭 종료 시 왼쪽 탭 포커스
활성 탭을 닫았을 때 같은 창의 왼쪽 탭으로 이동하도록 돕습니다. 목록 오른쪽에 상세 탭을 열어 탐색할 때 활용할 수 있습니다.
슬라이드 패널로 열기
확장 프로그램 아이콘을 누르면 브라우저 우측 사이드 패널에 옵션을 엽니다. 게시물과 목록을 나란히 보며 관리할 때 편리합니다.

화면 표시와 검색

의미 없는 댓글 가림
지원되는 페이지에서 ‘감사합니다’, ‘고맙습니다’ 같은 반복적인 짧은 댓글을 숨깁니다.
에브리띵 연결
추출된 책 제목으로 PC의 Everything 검색을 실행합니다. Everything 설치와 es: URL 연결 설정이 필요합니다. 이 옵션 안의 ‘Everything 연동 방법 확인하기’를 펼쳐 설정한 뒤 상세페이지의 검색 버튼을 사용하세요.
리스트 퀵 버튼 표시
지원되는 게시물 목록의 배지 아래에 등록·검색 등의 퀵 액션을 표시합니다.
마우스 오버 시에만 표시
‘리스트 퀵 버튼 표시’를 켠 상태에서 사용합니다. 마우스를 올렸을 때만 퀵 버튼을 보여 목록의 공간을 줄입니다.
1글자 매칭 지원
한글 한 글자 제목도 비교 대상에 포함합니다. 영어·숫자 한 글자는 제외됩니다. 짧은 제목은 다른 작품과 혼동될 수 있어 결과를 확인하세요.
게시판 전용 테마 적용
지원되는 게시판 목록의 디자인 일부를 변경합니다. 모든 사이트에 동일한 디자인을 적용하는 기능은 아닙니다.

게시물 숨김 처리

제외 / 완결 / 미완
선택한 타입과 매칭되는 게시물을 목록에서 숨깁니다. 제외는 매칭률이 95%를 넘는 경우 숨깁니다. 미완·완결 등 제외가 아닌 항목은 등록값보다 높은 권수·해상도 또는 누락 데이터가 있으면 보통 계속 표시됩니다.
번역 / 신작
번역으로 판별된 게시물이나 소장 목록에 매칭되지 않은 게시물을 숨깁니다. 번역 분류의 판별·우선 적용 방식은 사이트별로 다를 수 있습니다.
게시물 숨김 처리 퀵 메뉴 가리기
게시판 우측 하단의 숨김 설정 패널을 가립니다. 패널을 가려도 설정된 게시물 숨김 기능은 유지됩니다.
옵션 상단의 테마 스위치로 밝은 화면 / 어두운 화면을 바꿀 수 있습니다. 직접 선택하기 전에는 시스템 테마를 따릅니다. 이 안내 페이지도 같은 테마 설정을 따릅니다.

OPTION TAB 03

데이터 백업

파일로 보관 / 복구

  1. ‘내 PC로 데이터 백업’을 눌러 book_manager_backup.json 파일을 저장합니다.
  2. 다른 환경으로 옮기거나 복구할 때 ‘기존 데이터 복구’를 누릅니다.
  3. 백업 JSON 파일을 선택하고 덮어쓰기 안내를 확인합니다.

도서 목록, 누락 권수, 허용 사이트, 금지어, 판본 키워드를 백업합니다. 화면 테마와 모든 기능 체크박스까지 포함하는 전체 설정 백업은 아닙니다.

타임머신

자동으로 저장된 로컬 스냅샷에서 이전 상태로 복원합니다. 하루에 한 번 생성하며 최근 최대 7개 복원 지점을 보관합니다.

‘복원’ 전 날짜와 항목 수를 확인하세요. 확장 프로그램 내부에 저장되는 기록이므로 브라우저 데이터 삭제나 확장 프로그램 제거에 대비하려면 파일 백업도 보관하세요.

복구는 목록을 합치는 기능이 아니라 기존 데이터를 덮어쓰는 작업입니다. 현재 목록도 남겨야 한다면 먼저 파일로 백업하세요.

OPTION TAB 04

업데이트 내역

GitHub에 공개된 버전별 변경 사항과 게시 날짜를 불러옵니다. 인터넷 연결이 필요하며, 기록이 보이지 않으면 연결 상태를 확인하고 옵션 화면을 다시 열어보세요.

현재 버전 / 업데이트 확인
옵션 상단에서 설치된 버전을 확인합니다. 웹 스토어 설치본은 ‘업데이트 확인’으로 스토어 업데이트를 요청합니다. GitHub에 먼저 공개된 버전은 스토어 배포 대기로 표시될 수 있습니다.

자주 묻는 질문

등록했는데 제목 옆에 아무 표시도 없어요.

허용 사이트에 현재 도메인이 등록되어 있는지 확인하고 새로고침하세요. 상세페이지라면 제목 요소를 우클릭으로 등록합니다. 사이트 구조에 따라 일부 기능이 지원되지 않을 수 있습니다.

다른 작품이 매칭되거나 제목을 잘못 읽어요.

목록에서 추출된 제목을 확인하고 수정하세요. 너무 넓은 금지어, 짧은 제목, 별칭, 외국어 제목, 작품명에 포함된 숫자 등이 원인일 수 있습니다. 판본 키워드와 외전 표기도 확인하세요. 유사한 제목의 자동 매칭 결과는 직접 점검하는 것이 좋습니다.

숨김을 켰는데도 일부 도서가 보여요.

제외가 아닌 항목은 권수·해상도 업그레이드 또는 누락 데이터가 있으면 숨김의 예외가 될 수 있습니다. 제외는 매칭률 95% 이하일 때 제외 타입 숨김을 적용하지 않습니다. 번역 숨김은 사이트별 분류 규칙도 확인하세요.

누락 번호를 선택할 수 없어요.

도서 목록에서 권수를 먼저 숫자로 입력하고 ‘수정’으로 저장하세요. 이후 ‘+누락’을 누르면 저장한 권수까지 번호가 표시됩니다.

Everything 검색이나 바로다운로드가 작동하지 않아요.

Everything 설치와 es: URL 연결, 확장 프로그램의 연결 옵션을 확인하세요. 바로다운로드는 지원되는 링크와 페이지에서 제공됩니다. 사이트 등록만으로 모든 파일 호스팅의 다운로드가 지원되는 것은 아닙니다.

예시에서 등록했는데 내 도서 목록에는 없어요.

이 안내 페이지는 가상 데이터로 동작하는 체험 화면입니다. 실제 등록은 옵션의 ‘도서 목록 관리’ 또는 허용된 사이트의 등록 기능을 사용하세요. ‘예시 초기화’를 누르거나 페이지를 새로고침하면 체험 내용이 초기 상태로 돌아갑니다.
