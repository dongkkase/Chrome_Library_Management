TYPE & CATEGORY

타입과 분류는 따로 선택합니다

같은 작품의 만화와 전자책을 따로 관리할 수 있습니다. 게시판이 나뉘어 있지 않은 사이트에서도 등록할 때 분류를 직접 고르면 됩니다.

타입: 수집 상태

제외는 관심 없는 작품, 미완은 모으는 중인 작품, 완결은 수집을 마친 작품에 사용합니다. 게시물의 배지와 숨김 조건에 반영됩니다.

분류: 자료의 종류

미분류 · 만화 · 도서(EPUB) · 도서(PDF) · 도서(TXT) · 도서(SCAN) · 오디오북 · 영상 · 기타 중 하나를 선택합니다. 분류가 없던 기존 도서는 미분류로 표시됩니다.

등록 분류를 고르는 곳
퀵 버튼 맨 왼쪽의 ‘분류: 선택한 분류명’(아이콘 모드에서는 폴더 아이콘), 우측 하단 ‘게시물 숨김’ 옆의 분류 박스, 옵션의 일괄 등록 영역에서 고를 수 있습니다. 옵션에서는 타입 아래에 분류 선택란이 있습니다.
마지막 선택 유지
등록 분류는 이 선택란들이 함께 사용합니다. 직접 바꾸기 전까지 다른 탭과 브라우저를 다시 연 뒤에도 마지막 선택이 유지됩니다. 분류를 선택하기만 해서는 이미 등록한 책의 분류나 게시물 숨김 상태가 바뀌지 않습니다.
같은 제목을 다른 분류로
제목이 같아도 분류가 다르면 별도 항목으로 등록합니다. 기존 도서를 다른 분류로 옮기려면 도서 목록에서 해당 행의 분류를 바꾸고 저장하세요.
검색 분류는 별도 설정
도서 목록의 분류 필터는 등록 분류와 별도로 기억합니다. 필터를 바꾸거나 기존 도서의 분류를 수정해도 다음 등록에 사용할 분류는 바뀌지 않습니다.

제외

제목에 취소선을 표시합니다. 관심 없는 작품을 구분할 때 사용합니다.

미완

모으는 중인 작품입니다. 소장 권수와 해상도를 비교합니다.

완결

수집을 마친 작품입니다. 더 높은 사양의 게시물도 확인할 수 있습니다.

UP / 누락

UP은 등록값보다 높은 권수·해상도, 누락은 직접 지정한 빠진 권수입니다.

배지의 권수·해상도는 내가 등록한 값입니다. 게시물의 값이 더 높으면 해당 값 옆에 UP이 표시됩니다. 신작은 내 목록에 매칭되지 않은 게시물을 뜻하며 실제 출간 시점을 의미하지 않습니다.

표의 ‘게시판 구분’은 예시 사이트의 구획입니다. 내가 등록할 분류와 별개이며, 체험용 분류 선택은 실제 등록 분류나 소장 목록에 저장되지 않습니다.

이번에 정리한 도서의 권수와 이미지 해상도를 제목에 기재했습니다. 제목에서 읽은 정보와 내 소장 목록을 비교한 뒤 필요한 항목을 갱신하세요.

예시에는 실제 파일이나 다운로드 링크가 없습니다.

처음 사용하는 사이트라면

  1. 실제 사이트의 도서 상세페이지를 엽니다.
  2. 책 제목 위에서 마우스 오른쪽 버튼을 누릅니다.
  3. ‘이 요소를 상세페이지 제목으로 등록 (버튼 표시)’를 선택합니다.
  4. 필요하면 새로고침 후 제목 주변의 등록 버튼을 확인합니다.

작품 제목 부분을 정확히 지정하면 같은 사이트의 다른 상세페이지에서도 제목을 읽는 데 사용합니다.

빠르게 등록하는 다른 방법

  • 등록할 분류를 고른 뒤 게시물 제목 링크를 우클릭해 ‘제외 추가’, ‘미완 추가’, ‘완결 추가’를 선택합니다.
  • 링크가 없는 제목은 텍스트를 드래그한 뒤 우클릭 메뉴를 사용합니다.
  • 우클릭 등록에도 마지막으로 선택한 등록 분류가 적용됩니다.
  • 잘못 읽힌 제목·권수·해상도나 기존 도서의 분류는 옵션의 도서 목록에서 수정합니다.

여러 도서를 한 번에 등록하기

  1. ‘새로운 도서 일괄 등록’에서 저장할 타입을 선택합니다. 처음 기본값은 제외이며 이후 마지막으로 선택한 타입을 유지합니다. 모으는 중인 도서는 미완을 선택하세요.
  2. 타입 아래에서 분류를 고릅니다. 이번에 입력한 모든 줄에 같은 타입과 분류를 적용합니다.
  3. 한 줄에 한 작품씩 제목, 권수, 해상도를 입력합니다.
  4. 추출 미리보기를 확인하고 ‘목록에 일괄 추가하기’를 누릅니다.

같은 분류에서 제목과 판본이 같은 기존 항목은 입력 정보로 갱신합니다. 다른 분류의 동명 도서는 별도로 등록합니다. 같은 분류에 일치하는 기존 항목이 여러 개 있으면 중복을 정리한 뒤 등록해야 합니다.

분류 필터 / 제목 검색 / 정렬
제목 검색칸 왼쪽의 조절 아이콘에서 ‘전체 분류’ 또는 특정 분류를 고르고 제목 검색을 함께 사용합니다. 정렬 아이콘에서는 최신·오래된 등록순 또는 제목 가나다·역순을 선택합니다. 목록은 페이지 단위로 표시됩니다. 아이콘 버튼에 마우스를 올리거나 키보드로 초점을 맞추면 기능과 현재 선택값을 말풍선으로 확인할 수 있습니다.
목록 찾기
‘중복 찾기’는 같은 분류 안에서 제목이 겹치는 항목, ‘누락 찾기’는 빠진 권수가 등록된 항목을 찾습니다. ‘폴더 규칙 찾기’를 선택한 뒤 규칙명을 입력할 수도 있습니다. 선택한 분류 필터도 함께 적용됩니다. 검색어 예: #중복, #누락, #폴더규칙:만화.
검색된 결과 타입 및 분류 일괄 변경
타입과 분류를 각각 고르고 ‘일괄 적용’을 누릅니다. ‘변경 안 함’은 기존 값을 유지하므로 타입만, 분류만, 또는 둘 다 바꿀 수 있습니다. 현재 분류 필터와 검색 조건에 맞는 모든 페이지의 결과가 대상입니다. 확인창의 건수와 변경 내용을 확인하세요. ‘전체 분류’에서 검색을 비우면 전체 목록에 적용합니다.
행별 저장 / 삭제
제목 왼쪽의 분류 선택란과 타입, 제목, 해상도, 권수, 상위 폴더 규칙을 고친 뒤 디스크 모양 저장 아이콘을 누릅니다. 휴지통 모양 삭제 아이콘은 해당 도서를 목록에서 제거합니다. 아이콘에 마우스를 올리거나 초점을 맞추면 ‘저장’ 또는 ‘삭제’ 말풍선이 표시됩니다. 지원되는 작업은 화면 우측 하단 ‘실행 취소’로 되돌릴 수 있습니다.
작업 중 표시
저장·삭제·일괄 적용 등의 작업을 처리하는 동안 버튼 중앙에 로딩 표시가 나타납니다. 같은 버튼의 반복 실행은 잠시 막히며, 처리가 끝나면 원래 표시로 돌아옵니다. 오류 안내가 나오면 내용을 확인한 뒤 다시 시도하세요.
제목정정
제목 입력칸에 올바른 이름을 적은 뒤 옆의 ‘제목정정’을 누르면 같은 분류에서 기존 제목이 동일한 항목을 함께 고칩니다. 이후 제목 인식에 사용할 보정 규칙도 저장합니다. 확인창에 표시되는 대상 수와 변경할 제목을 확인하세요.
상위 폴더 규칙
자동 폴더 다운로드 시 책 폴더 위에 둘 분류 경로입니다. 예: 만화/연재. 입력칸의 경로 미리보기로 결과를 확인하고 저장합니다. 규칙 옆 일괄 변경 버튼으로 같은 규칙을 사용하는 항목을 함께 수정할 수 있습니다.
+누락 / 누락 배지
먼저 숫자로 된 권수를 입력하고 저장 아이콘을 누릅니다. 권수 옆 배지를 누른 뒤 빠진 번호를 클릭하면 자동 저장됩니다. 다시 누르면 누락이 해제됩니다. 예: 5권까지 소장했지만 2권이 없으면 2를 선택합니다.

OPTION TAB 02

사이트 및 설정

어디에서 작동할지, 제목을 어떻게 읽을지, 어떤 보조 기능을 사용할지 설정합니다. 체크박스 변경은 바로 저장됩니다.

필요한 영역만 펼쳐두세요. 새로운 도서 일괄 등록, 작동 허용 사이트, 제목 파싱 금지어, 판본 키워드, Everything 연동 안내, 표시할 퀵 메뉴, Google 동기화는 ‘접기 / 펼치기’ 글자와 화살표로 여닫습니다. 각 영역은 부드럽게 접히고 펼쳐지며, 마지막 상태를 기억해 옵션창이나 브라우저를 다시 열어도 유지합니다.

사이트와 제목 인식

작동 허용 사이트 / 상세 제목
실제 사용할 도메인을 입력하고 ‘수동 추가’를 누릅니다. 입력 형식 예시는 books.example.com입니다. 상세 제목은 실제 페이지에서 우클릭으로 지정합니다. 등록 항목의 ×는 해당 사이트 등록을 삭제합니다.
제목 파싱 금지어
작가명이나 반복되는 홍보 문구처럼 제목 비교 전에 제거할 문자열을 등록합니다. 예: ‘샘플편집팀’을 등록하면 ‘별빛 도서관 샘플편집팀’에서 해당 문구를 제거합니다. 실제 작품명에 들어가는 일반 단어는 신중하게 추가하세요.
판본 식별 괄호 키워드
‘신장판’처럼 판본을 구분하는 단어를 보존합니다. ‘별빛 도서관(신장판)’과 ‘별빛 도서관 신장판’은 같은 판본으로, 일반판과는 별도 작품으로 매칭합니다.

다운로드와 브라우저 동작

단축키 사용
기본값은 꺼짐입니다. 켜면 지원되는 사이트에서 D로 링크를 열람하고, 열람 후 다시 누르면 바로다운로드를 실행합니다. 여러 주소는 선택 창에서 1~9 또는 다운로드 버튼으로 선택합니다. 10개 이상이면 이전·다음 버튼이나 좌우 방향키로 이동하며, Esc로 닫습니다. 글을 입력하는 중이거나 실행 가능한 버튼이 없으면 동작하지 않습니다.
다운로드 시 미완·완결 자동 업데이트
‘단축키 사용’의 하위 옵션이며 기본값은 꺼짐입니다. 단축키로 다운로드를 요청할 때만 적용합니다. 제목에 ‘완결’이 있으면 완결로, 그 외에는 저장된 권수보다 높은 권수를 받을 때 미완으로 갱신합니다. 6권까지 저장된 도서의 9권을 받으면 최고 권수는 9권, 누락은 7·8권으로 기록합니다. 이후 7권을 받으면 최고 권수를 유지하며 누락에서 7권만 제거합니다. 범위로 표시된 권수도 반영하며 미등록 도서는 자동 등록합니다. 미등록 도서의 단일 9권을 받으면 1~8권을 누락으로 기록합니다. 권수를 인식하지 못한 경우 완결 표시만 반영할 수 있습니다. 링크 열람만 하거나 다운로드 버튼을 직접 클릭하면 갱신하지 않습니다.
에브리띵 같이 검색
‘단축키 사용’의 하위 옵션이며 기본값은 꺼짐입니다. 지원되는 사이트에서 단축키로 다운로드를 요청할 때 해당 도서 제목으로 Everything도 검색합니다. 여러 주소의 선택 창에서는 다운로드할 주소를 선택한 시점에 실행합니다. 링크 열람만 하거나 다운로드 버튼을 직접 클릭하면 실행하지 않습니다. 도서 상태 자동 업데이트와 별도로 사용할 수 있습니다. Everything 설치와 es: 연결이 필요하며, 아래 ‘에브리띵 연결’의 안내를 참고하세요.
Buzzheavier 바로다운로드
지원되는 게시물의 Buzzheavier 공유 링크 옆에서 ‘바로다운로드’를 누릅니다. 주소 확인용 탭이 잠시 열렸다가 다운로드가 시작되면 닫힙니다. 브라우저 보안 확인이 필요한 경우에는 해당 탭이 표시됩니다. 확인을 마친 뒤 원래 게시물의 ‘바로다운로드’를 다시 누르세요. 폴더 지정과 다운로드 현황판, 활성화한 다운로드 단축키도 함께 사용할 수 있습니다.
자동 폴더 생성 다운로드
지원되는 바로다운로드 기능을 사용할 때 책 제목으로 폴더를 만듭니다. 도서에 상위 폴더 규칙이 있으면 함께 반영합니다. 일반적인 모든 웹 다운로드에 적용되는 설정은 아닙니다.
다운로드 현황판 표시
지원되는 다운로드의 진행 상황을 화면 좌측 하단 현황판에 표시합니다.
확인창(Confirm) 자동 스킵
지원되는 페이지의 반복 확인창을 자동으로 넘깁니다. 포인트 차감 같은 확인도 포함될 수 있으므로 내용을 직접 확인하려면 꺼두세요.
활성 탭 종료 시 왼쪽 탭 포커스
활성 탭을 닫았을 때 같은 창의 왼쪽 탭으로 이동하도록 돕습니다. 목록 오른쪽에 상세 탭을 열어 탐색할 때 활용할 수 있습니다.
슬라이드 패널로 열기
확장 프로그램 아이콘을 누르면 브라우저 우측 사이드 패널에 옵션을 엽니다. 게시물과 목록을 나란히 보며 관리할 때 편리합니다.

아이콘·로고로 간단히 표시
글자 버튼을 아이콘으로 줄여 표시합니다. 구글·리디·Everything 검색에는 서비스 로고를 사용합니다. 마우스를 올리거나 키보드로 초점을 맞추면 이름을 확인할 수 있습니다. 기본값은 꺼짐이며 목록과 상세 화면에 함께 적용됩니다.
미니 모드로 표시

OPTION TAB 03

데이터 백업

여러 기기의 목록을 맞추는 Google 동기화, 직접 보관하는 파일 백업, 이 기기의 이전 목록으로 돌아가는 타임머신을 제공합니다.

Google 도서 목록 동기화 시작하기

  1. ‘Google 도서 목록 동기화’를 펼치고 ‘Google 계정 연결’을 누릅니다. 계정을 선택하고 Google Drive 접근을 허용합니다.
  2. 다른 기기에서도 같은 Google 계정을 연결합니다. 도서의 타입·분류를 포함한 목록과 누락 권수를 함께 맞출 수 있습니다.
  3. 상태와 ‘이 기기 최근 동기화 완료’ 시각을 확인합니다. 바로 맞추려면 ‘지금 동기화’를 누릅니다.

Chrome 웹 스토어 설치본이나 동기화를 지원하는 직접 설치본에서 사용할 수 있습니다. 분류를 함께 사용하려면 다른 기기도 분류 지원 버전으로 업데이트하세요. Google 계정을 연결하기 전에는 도서 목록을 업로드하지 않습니다.

동기화되는 내용
도서 목록과 누락 권수를 연결한 Google 계정의 Drive 앱 전용 공간에 저장합니다. 일반 Drive 파일 목록이나 검색에는 나타나지 않습니다. 사이트 설정, 등록 분류의 마지막 선택, 화면 설정과 이 기기의 복원 지점은 동기화 대상이 아닙니다.
자동 확인 주기
‘동기화 옵션’에서 자동 동기화를 켜거나 끄고 5·15·30·60분 중 확인 간격을 고릅니다. Chrome 시작 시와 도서 목록·누락 권수 변경 시 확인할지도 각각 선택할 수 있습니다. 변경 후 확인은 약 30초 뒤 실행되며, Chrome 실행 중 인터넷 연결과 Google 로그인이 유지되어야 합니다. 브라우저 상태에 따라 늦어질 수 있습니다.
수동으로만 동기화하기
자동 동기화를 꺼도 계정을 연결할 때는 한 번 확인하며, ‘지금 동기화’는 계속 사용할 수 있습니다. 동기화 옵션은 이 기기에만 저장되고 연결을 해제해도 유지됩니다.
사용할 목록 선택
처음 연결한 두 목록이 다르거나 양쪽에서 수정했을 때, 적용 과정에서 도서가 삭제될 때, 파일 복구·전체 교체 후에는 자동 적용을 멈추고 확인을 요청할 수 있습니다. 기존 Google 목록을 찾을 수 없거나 다른 목록으로 바뀐 경우에도 확인합니다. 안내된 추가·수정·삭제 건수를 읽고 사용할 목록을 고르세요.
목록 선택 버튼: 확인이 필요할 때만 표시
옵션의 ‘데이터 백업 → Google 도서 목록 동기화’를 펼치면, 사용할 목록을 확인해야 하는 상태에서만 ‘동기화 옵션’ 아래에 두 버튼이 나타납니다. 평소 동기화가 정상인 상태에서는 보이지 않습니다. ‘이 기기 목록 사용’은 이 기기 목록으로 Google 목록 전체를 교체하고, ‘Google 목록 사용’은 Google 목록으로 이 기기 목록 전체를 교체합니다. 두 목록을 합치는 동작이 아닙니다. 기존 Google 파일을 찾을 수 없는 경우에는 ‘이 기기 목록 사용’만 표시됩니다. 교체 전 목록을 먼저 이 기기의 복원 지점에 보관하며, 확인 후 목록이 달라졌으면 다시 선택해야 합니다.
연결 해제와 오류 확인
‘연결 해제’는 이 기기의 동기화를 중지합니다. 이 기기와 Google에 저장된 목록은 유지됩니다. 동기화 오류나 확인 요청은 접힌 영역의 표시에서도 알 수 있으며, 영역을 펼쳐 원인을 확인한 뒤 다시 연결하거나 동기화를 실행하세요.

파일로 보관 / 복구

  1. ‘내 PC로 데이터 백업’을 눌러 book_manager_backup.json 파일을 저장합니다.
  2. 다른 환경으로 옮기거나 복구할 때 ‘기존 데이터 복구’를 누릅니다.
  3. 백업 JSON 파일을 선택하고 덮어쓰기 안내를 확인합니다.

타입·분류를 포함한 도서 목록, 누락 권수, 허용 사이트, 금지어, 판본 키워드를 백업합니다. 화면 테마와 모든 기능 체크박스까지 포함하는 전체 설정 백업은 아닙니다.

타임머신: 두 종류의 복원 지점

일일 복원 지점은 최근 7개를 보관합니다. 브라우저 시작이나 정기 확인 시 하루에 한 번 자동으로 생성합니다.

Google 동기화 전 복원 지점은 최근 10개를 별도로 보관합니다. Google 목록을 교체하기 전에는 기존 Google 목록을, 이 기기 목록을 교체하기 전에는 현재 기기 목록을 저장합니다.

날짜와 항목 수를 확인한 뒤 ‘이 시점으로 복원’을 누르세요. 복원은 이 기기에 적용하며 다른 기기에 반영하기 전 다시 확인합니다. 복원 지점은 이 기기 안에 보관되므로 파일 백업도 별도로 보관하세요.

파일 복구와 타임머신 복원은 기존 목록을 덮어씁니다. 현재 목록도 남겨야 한다면 먼저 파일로 백업하세요. 직접 설치본을 동기화 지원 배포본으로 처음 바꿀 때에도 파일 백업을 보관한 뒤 전환하세요.

5권까지 등록한 도서의 ‘+누락’에서 2권을 선택합니다. ‘목록 찾기 → 누락 찾기’로 모아보고, 해당 권을 확보한 뒤 누락 번호를 다시 눌러 해제합니다.

목록 정돈

확인할 게시물에 집중

관심 없는 작품은 제외 타입으로 등록하고 제외 숨김을 켭니다. 수집을 마친 도서는 완결 타입으로 관리합니다. 게시물이 너무 적어지면 퀵 메뉴에서 숨김 조건을 점검합니다.

소장 파일 확인

검색과 폴더 정리 연결

Everything 연동으로 같은 제목의 로컬 파일을 검색합니다. 자동 폴더 생성과 ‘만화/연재’ 같은 상위 폴더 규칙을 함께 사용해 지원되는 다운로드를 분류합니다.

여러 형태의 같은 작품

만화와 EPUB을 따로 관리

만화는 ‘만화’, 전자책은 ‘도서(EPUB)’를 선택해 같은 제목으로 등록합니다. 옵션에서 분류 필터를 사용하면 각각의 권수와 타입을 따로 확인할 수 있습니다.

기기 간 목록 이동

두 기기에서 같은 목록 사용

두 기기에서 같은 Google 계정을 연결합니다. 처음 목록이 다르면 추가·수정·삭제 건수를 확인하고 기준으로 삼을 목록을 선택합니다. 사이트 설정까지 옮기려면 파일 백업과 복구를 사용하세요.

도서 외의 연속 자료도 제목을 기준으로 목록을 관리할 수 있습니다. 다만 권수·해상도 추출은 도서 제목 형식에 맞춰져 있으므로 등록 미리보기를 확인하세요.

HELP

자주 묻는 질문

등록했는데 제목 옆에 아무 표시도 없어요.

허용 사이트에 현재 도메인이 등록되어 있는지 확인하고 새로고침하세요. 상세페이지라면 제목 요소를 우클릭으로 등록합니다. 사이트 구조에 따라 일부 기능이 지원되지 않을 수 있습니다.

다른 작품이 매칭되거나 제목을 잘못 읽어요.

목록에서 추출된 제목을 확인하고 수정하세요. 너무 넓은 금지어, 짧은 제목, 별칭, 외국어 제목, 작품명에 포함된 숫자 등이 원인일 수 있습니다. 판본 키워드와 외전 표기도 확인하세요. 유사한 제목의 자동 매칭 결과는 직접 점검하는 것이 좋습니다.

숨김을 켰는데도 일부 도서가 보여요.

제외가 아닌 항목은 권수·해상도 업그레이드 또는 누락 데이터가 있으면 숨김의 예외가 될 수 있습니다. 제외는 매칭률 95% 이하일 때 제외 타입 숨김을 적용하지 않습니다. 번역 숨김은 사이트별 분류 규칙도 확인하세요.

누락 번호를 선택할 수 없어요.

도서 목록에서 권수를 먼저 숫자로 입력하고 디스크 모양 저장 아이콘을 누르세요. 이후 ‘+누락’을 누르면 저장한 권수까지 번호가 표시됩니다.

검색 분류를 바꿨는데 새 책은 다른 분류로 등록돼요.

검색 분류와 등록 분류는 서로 독립적입니다. 퀵 버튼 왼쪽이나 ‘게시물 숨김’ 옆 분류 박스, 옵션의 일괄 등록 영역에서 등록 분류를 바꾸세요. 마지막으로 선택한 등록 분류를 계속 사용합니다.

분류를 골랐는데 기존 책의 분류는 그대로예요.

등록 분류 선택은 앞으로 등록할 책에 적용합니다. 기존 책은 목록의 제목 왼쪽 분류 선택란에서 고친 뒤 저장 아이콘을 누르세요. 여러 책은 분류 필터와 제목 검색으로 대상을 확인한 뒤 ‘검색된 결과 타입 및 분류 일괄 변경’을 사용할 수 있습니다.

Google 동기화가 사용할 목록을 선택하라고 해요.

양쪽 목록이 다르거나 삭제·복원 등의 확인이 필요한 상태입니다. 추가·수정·삭제 건수를 확인하세요. ‘이 기기 목록 사용’은 Google 목록을, ‘Google 목록 사용’은 이 기기 목록을 전체 교체합니다. 선택을 기다리는 동안에는 자동으로 교체하지 않습니다.

Google Drive에서 동기화 파일을 찾을 수 없어요.

도서 목록은 일반 파일 목록과 검색에 표시되지 않는 앱 전용 공간에 저장됩니다. 동기화 여부는 옵션의 ‘데이터 백업 → Google 도서 목록 동기화’에서 확인하세요.

Everything 검색이나 바로다운로드가 작동하지 않아요.

Everything 설치와 es: URL 연결, 확장 프로그램의 연결 옵션을 확인하세요. 바로다운로드는 지원되는 링크와 페이지에서 제공됩니다. 사이트 등록만으로 모든 파일 호스팅의 다운로드가 지원되는 것은 아닙니다.

예시에서 등록했는데 내 도서 목록에는 없어요.

이 안내 페이지는 가상 데이터로 동작하는 체험 화면입니다. 실제 등록은 옵션의 ‘도서 목록 관리’ 또는 허용된 사이트의 등록 기능을 사용하세요. ‘예시 초기화’를 누르거나 페이지를 새로고침하면 체험 내용이 초기 상태로 돌아갑니다.
